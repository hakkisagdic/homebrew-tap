# hakkisagdic/tap

```bash
brew tap hakkisagdic/tap
brew install agent-orchestrator
```

Installs `ao` — attach to the coding agent you are already running: watch it,
restart it when it stalls, run its gates independently, and decide from that
evidence what may be committed.

- Source: https://github.com/hakkisagdic/agent-orchestrator
- Docs: https://hakkisagdic.github.io/agent-orchestrator/

The formula here is generated from `packaging/homebrew/` in the main repository;
edit it there and copy it across at release time, so the two cannot disagree
about which archive is pinned.
